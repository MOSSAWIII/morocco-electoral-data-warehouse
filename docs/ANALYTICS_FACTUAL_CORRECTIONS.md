# Registre des corrections factuelles candidates

Ce registre sépare les constats analytiques des modifications du warehouse
canonique. Une entrée doit indiquer la table et la clé canoniques, la valeur
observée, la correction proposée, la source probante et son état de revue.

| Table canonique | Clé | Valeur observée | Correction proposée | Preuve | État |
|---|---|---|---|---|---|

Aucune correction factuelle n'est actuellement proposée. Toute future entrée
doit être portée vers `main` dans un commit ou une pull request distincte ; le
build analytique ne modifie jamais la base canonique.
