# Politique de licence des données

Le paquet V13 est une base composite. Les droits sur les contenus sources restent régis source par source par la colonne `license` de la table `sources`, par `metadata/source_manifest.json` et par `ATTRIBUTIONS.md`.

La structure originale de la base, la sélection des champs et les transformations produites par ce projet sont proposées sous Open Data Commons Open Database License 1.0 (ODbL 1.0) :

https://opendatacommons.org/licenses/odbl/1-0/

Cette licence n'accorde aucun droit que le projet ne détient pas sur un contenu tiers. En particulier :

- les jeux TAFRA/openAFRICA signalés `CC BY 4.0` conservent cette licence et leur attribution ;
- les ressources du Parlement diffusées via data.gov.ma conservent leur licence ODbL déclarée ;
- les données HCP conservent leurs conditions officielles; les fichiers sources HCP ne sont pas redistribués dans le dépôt ;
- les sources dont les conditions restent à confirmer ne doivent pas être redistribuées indépendamment sur la seule base de cette politique.

Toute réutilisation doit conserver les identifiants de source et les attributions. Une valeur `official public` décrit la provenance publique; elle ne doit pas être interprétée comme une licence universelle accordée par ce projet.
