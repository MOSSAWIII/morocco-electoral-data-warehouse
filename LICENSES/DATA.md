# Politique de licence des données

Le Morocco Electoral Data Warehouse est une base composite. Les droits sur les contenus sources restent régis source par source par le registre canonique et par `ATTRIBUTIONS.md`.

La structure originale de la base, la sélection des champs et les transformations produites par ce projet sont proposées sous Open Data Commons Open Database License 1.0 (ODbL 1.0), sous réserve des droits propres aux contenus tiers :

https://opendatacommons.org/licenses/odbl/1-0/

Cette licence n'accorde aucun droit que le projet ne détient pas sur un contenu tiers. Les fichiers RAW utilisés comme preuves ne sont pas inclus dans le paquet public lorsque leur redistribution n'est pas établie ; leur registre conserve URL, taille et SHA-256, et toute acquisition divergente est refusée.

- les jeux TAFRA/openAFRICA signalés `CC BY 4.0` conservent cette licence et leur attribution ;
- les ressources du Parlement diffusées via data.gov.ma conservent leur licence déclarée ;
- les données HCP conservent leurs conditions officielles ;
- une source dont les conditions restent à confirmer ne peut pas être redistribuée sur la seule base de cette politique.

Toute réutilisation doit conserver les identifiants de source et les attributions. Les autorisations de publication sont des décisions externes, datées et liées au SHA-256 exact du contenu dans `metadata/warehouse/publication_reviews.json`; le build les vérifie mais ne les crée pas.
